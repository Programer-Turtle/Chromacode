# Chromacode

![Version](https://img.shields.io/badge/version-0.2-blue)
![License](https://img.shields.io/badge/license-MIT-green)

> **Warning**
> Chromacode is an experimental format under active development.
> The specification is incomplete and compatibility is not guaranteed until v1.0.

Chromacode is a high-density multicolor barcode format designed to hold more data than traditional QR codes. Chromacode achieves this by using more than the two colors found in traditional QR codes, allowing more information to be encoded per pixel.

This repository contains the official specification for Chromacode. The project is still under development and is not ready for serious use yet. However, if you want to build something cool, experiment with the format, or contribute, feel free to get involved.

## Features

- Higher data density than traditional QR codes
- Customizable color density
- Single tracking square
- Multiple read modes
