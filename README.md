# Chromacode

![Version](https://img.shields.io/badge/version-0.1-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Chromacode is a high-density multicolor barcode format designed to hold more data than traditional QR codes.

This repository contains the official specification for Chromacode. The project is still under development and is not ready for serious use yet. However, if you want to build something cool, experiment with the format, or contribute, feel free to get involved.

## features

- Higher data density than traditional QR codes
- Customizable color density
- Single tracking square
- Multiple read modes

## Roadmap

I plan to work on an decoder, barcode generator, and a scanner. A more detailed roadmap will be made for v0.2.
